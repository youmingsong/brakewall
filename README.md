# 飞镖大亨（砸墙达人）

> 
> 一款无尽模式 HTML5 砸墙小游戏，浏览器直接打开就能玩，支持局域网 / 公网静态网页部署，无需安装任何软件。

## 🎮 游戏介绍

本游戏为单机无尽闯关玩法：右侧电路板风格墙体持续向左推进，墙体碰到左侧边界则游戏结束。
玩家投掷螺丝刀、斧头（大锤）、扳手（爆炸飞镖）打碎墙砖获取分数与金币，连续命中同一块砖块触发连击奖励；可购买机器人自动协助砸墙。
角色成长特色：4 级之后身高不再增长，**5 级起逐步长出额外投掷手臂，满级进化为三头六臂**，画风诡异充满乐趣。

### ✨ 核心特色

- 🧱 电路板 ECU 材质墙砖，打碎有电子裂纹与电路板粒子破碎特效
- 🎯 蓄力投掷机制，不同道具拥有独立外观、飞行动画、专属音效
  - 螺丝刀（普通飞镖）：投掷语音 “80”
  - 斧头（大锤）：投掷语音 “大锤 100”，砸墙触发玻璃破碎音效
  - 扳手（爆破飞镖）：旋转飞行，投弹呼啸音效，爆炸爆破特效
- 🤖 机器人自动往返砸墙：从底向上砸，到达顶端掉头向下循环挥斧攻击，独立攻击逻辑**不占用玩家连击计数**
- 📈 升级机制：升级经验指数增长，升级触发全屏金色爆发特效 + 经验进度条；4 级身高封顶，5 级解锁多手臂，满级三头六臂
- 🛒 商店系统：金币购买机器人，提升游戏自动作战能力
- 🖥️ 底部 LED 电子屏：实时时钟 + 自定义走马灯文字，边框灯交替闪烁，复刻门店门头电子屏效果
- 📱 纯前端实现：单 HTML 文件，支持横 / 竖屏切换，手机、电脑浏览器均可打开游玩

## 🎮 操作说明

1. **蓄力投掷**：鼠标按住蓄力，松开发射道具；蓄力越久，投射距离越远
2. **武器槽**：左侧黑色武器槽，优先使用特殊武器，用完自动填充螺丝刀
3. **商店**：点击商店按钮，消耗金币购买机器人，增加自动砸墙单位
4. **音效开关**：一键控制全部游戏音效

## 📦 部署方式

> 
> 本项目为纯静态 HTML 游戏，**无后端、无数据库**

1. **本地游玩**：直接打开 `dart-game.html` 文件，浏览器即可运行
2. **局域网游玩**：使用小皮面板 (phpStudy) Nginx/Apache 托管，同局域网设备访问本机 IP
3. **公网部署**：
   - GitHub Pages / Cloudflare Pages / 对象静态存储托管
   - 全部素材推荐内嵌 Base64，避免图片资源丢失

> 
> ⚠️ 注意：所有玩家存档（最高分、分数记录）保存在**浏览器本地 localStorage**，玩家之间数据互不互通，没有联机排行榜。

## ⚙️ 项目说明

- 画布尺寸：1200 × 700
- 墙砖逻辑：靶盘升级后，墙砖行数减少，砖块自动放大，保持墙体总高度不变，最少保留 6 行墙砖
- 性能优化：大量墙砖渲染优化，碎砖块自动回收，多机器人运行保持流畅
- 音效：Web Audio API 原生合成音效，支持音量调节

## ⚠️ 注意事项

1. GitHub Pages 国内访问可能不稳定，可搭配 Cloudflare Pages 加速访问
2. 公开仓库上传后，任何人都可以下载完整源码与素材
3. 浏览器需要允许音频播放：浏览器策略限制，**必须点击页面交互后音效才会播放**
4. 建议使用 Chrome、Edge 现代浏览器，老旧浏览器会出现动画 / 音频异常
